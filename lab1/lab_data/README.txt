ИСХОДНЫЕ ДАННЫЕ ДЛЯ ЛАБОРАТОРНОЙ РАБОТЫ № 1

Назначение: шесть независимых вариантов исходных данных для разных студенческих команд, выбираете один доступный датасет на команду. Желательно, чтобы у каждый команды был свой датасет, если хватит.
Каждый CSV-файл содержит 450 пользовательских сообщений:
- присутствуют URL, e-mail, телефонные номера, даты и цены в разных форматах;
- встречаются лишние пробелы, повторяющиеся знаки пунктуации, разные регистры, emoji и спецсимволы;
- присутствуют отдельные опечатки и нестандартные записи;
- используются разные словоформы, пригодные для токенизации, удаления стоп-слов и лемматизации.

Структура файлов:
message_id  - идентификатор сообщения;
channel     - канал поступления сообщения;
created_at  - дата и время поступления;
message     - исходный «грязный» текст.

Варианты:
01_internet_magazin.csv - сообщения интернет-магазина;
02_universitetskiy_servis.csv - обращения к университетскому сервису;
03_dostavka_i_logistika.csv - обращения по доставке и логистике;
04_bronirovanie_i_meropriyatiya.csv - бронирования, билеты и мероприятия;
05_tehnicheskaya_podderzhka.csv - техническая поддержка цифрового сервиса;
06_obyavleniya_i_uslugi.csv - сервис объявлений и услуг.

Кодировка CSV: UTF-8 with BOM. Разделитель: запятая.
Файлы содержат только исходные данные
